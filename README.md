# ONDA Menu — browse

The public "browse restaurants" page for ONDA Menu, served at https://browse.onda.menu
(GitHub Pages). It reads public menu data (restaurants and dishes, text only) from the
ONDA Menu Xano endpoint `GET api:menu/browse`.

Source of truth: `onda_menu/web/browse/index.html` in the private app repo — copy it here to publish.
